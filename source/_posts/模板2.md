## 二、安装前准备

1. **系统 & 硬件**
   - Windows 11 家庭版中文，64 位。
   - 建议至少 16GB 内存，7B 模型大概需要 5GB+ 内存。csdn.net
   - 磁盘空间：模型 + 向量库预留 30GB 以上比较安心。
2. **网络**
   - 安装 Ollama / 拉模型、注册 DeepSeek API 时需要联网。
   - 日常使用时，如果只用本地模型，可以断网。
3. **账号**
   - 需要一个 DeepSeek 开发者账号，用来买 Token、拿 API Key。deepseek.com+1

## 三、安装 Ollama + nomic-embed-text（纯本地）

### 3.1 下载安装 Ollama

1. 打开：https://ollama.com/download/windows
   下载 `OllamaSetup.exe`。modelscope.cn+1
2. 双击安装，默认会装在 C 盘（`C:\Users\用户名\AppData\Local\Programs\Ollama`），**安装路径暂时不能改**。csdn.net+1
3. 安装完成后，打开 **命令提示符** 或 **PowerShell**，验证：

```
   ollama --version
```

  能看到版本号就说明安装成功。826pc.com

> Ollama 是本地模型引擎，**不会自动把你的数据上传**，只在本机跑模型。csdn.net

### 3.2 （推荐）把模型存到非 C 盘

默认模型路径：`C:\Users\用户名\.ollama\models`readthedocs.io+1
如果 C 盘紧张，建议提前改到 D/E 盘：

1. 在 D 盘新建目录，例如：`D:\OllamaModels`
2. 设置系统环境变量：
   - 右键“此电脑” → 属性 → 高级系统设置 → 环境变量。
   - 在“系统变量”中新建：
     - 变量名：`OLLAMA_MODELS`
     - 变量值：`D:\OllamaModels`csdn.net+1
3. 重启 Ollama 服务（退出托盘图标再重新打开，或重启电脑）。csdn.net

### 3.3 拉取 DeepSeek 本地模型 + nomic-embed-text

1. 拉一个本地 DeepSeek 模型（示例用 7B，你按自己显存/内存选）：

```
   ollama pull deepseek-r1:7b
```

  也可以选 `deepseek-r1:8b` 等。826pc.com+1

1. 拉取嵌入模型 `nomic-embed-text`：

```
   ollama pull nomic-embed-text
```

  这是 Ollama 官方支持的嵌入模型，专为长文本优化，支持多语言。csdn.net+2

1. 检查模型列表：

```
   ollama list
```

  应该能看到类似：

```
   deepseek-r1:7b
   nomic-embed-text
```

> 至此，Ollama + nomic-embed-text 已完全在本地，**不会把文档内容发到外面**。csdn.net+1

## 四、安装 AnythingLLM Desktop（本地知识库本体）

### 4.1 下载安装

1. 打开官网：https://anythingllm.com/desktop
   下载 Windows 桌面版安装包（通常叫 `AnythingLLMDesktop.exe`）。jb51.net+1
2. 双击安装，选择安装位置（建议装在 D 盘，避免 C 盘爆）。xmu.edu.cn
3. 安装完成后，桌面会有 **AnythingLLM** 图标。

> AnythingLLM Desktop 所有数据都存在本地，默认路径：
> `C:\Users\<用户名>\AppData\Roaming\anythingllm-desktop\storage`xmu.edu.cn+2

### 4.2 首次启动 & 简单向导

1. 双击 AnythingLLM 图标，首次启动会进入向导：
   - 第一步：直接点 **Get started**。
   - 后面几步可以先默认，一路“下一步”，工作区名称可以起 `本地知识库`。
2. 进入主界面后，**先不要配置 DeepSeek API**，先只接本地 Ollama，保证数据安全。

## 五、在 AnythingLLM 里配置“本地 Ollama + nomic-embed-text”

### 5.1 配置 LLM 提供商（先用本地 DeepSeek，暂不用 API）

1. 在 AnythingLLM 左下角点击 **小扳手（Settings）**。jb51.net+1

2. 找到

    

   LLM Preference / LLM 首选项

   ：

   - Provider：选择 **Ollama**。
   - Base URL：`http://127.0.0.1:11434`（Ollama 默认地址）。csdn.net+1
   - Model：选择 `deepseek-r1:7b`（你刚在 Ollama 拉的本地模型名）。

3. 保存 / Update workspace。

> 这样配置后，**聊天模型只走本机 Ollama，不会调用 DeepSeek 云端 API**。csdn.net+1

### 5.2 配置 Embedding 提供商（nomic-embed-text，纯本地）

1. 仍在设置里，找到

    

   Embedding Preference / 嵌入首选项

   ：

   - Provider：选择 **Ollama**。
   - Base URL：`http://127.0.0.1:11434` 。
   - Model：选择 `nomic-embed-text:latest`（或你看到的 `nomic-embed-text`）。csdn.net+2

2. 保存设置。

> 这样所有文档的向量化都由本地 `nomic-embed-text` 完成，**不会把文本发到 OpenAI 等云端嵌入服务**。csdn.net

### 5.3 配置向量数据库（LanceDB，默认本地）

1. 在设置里找到

    

   Vector Database / 向量数据库

   ：

   - 默认就是 **LanceDB**，这是本地嵌入式向量库，数据全在本地文件里。csdn.net+1
   - 不要选 Pinecone / Weaviate 等云端向量库，否则向量会存到云上。

2. 保存设置。

### 5.4 创建工作区 & 上传文档（本地知识库）

1. 在左侧工作区列表，点击 **New Workspace**，起个名字，例如 `内部知识库`。csdn.net+1

2. 进入该工作区，点击

    

   上传按钮

   ，选择本地文件：

   - 支持格式：TXT、PDF、DOCX、Excel 等。csdn.net+1

3. 选中文档 → 点击

    

   Move to Workspace

    

   → 再点

    

   Save and Embed

   ：

   - AnythingLLM 会调用 Ollama 的 `nomic-embed-text` 把文档切分并向量化，存到本地 LanceDB。csdn.net+2

4. 等待状态显示 **“Workspace updated successfully”** 即完成。

> 至此，你已经有了一个完全本地的 RAG 知识库：
> 文档 → 本地 nomic-embed-text 向量化 → 本地 LanceDB → 本地 DeepSeek-r1:7b 生成回答，**全程数据不出机器**。

### 5.5 设置“只基于知识库回答，不胡编”

1. 在工作区设置里找到

    

   Chat Settings / 聊天设置

   ：

   - Chat Mode：选 **Query**（而不是 Chat）。
     Query 模式：只在检索到相关文档时才回答，否则会说“未找到相关内容”，减少胡编。csdn.net+1

2. 在 System Prompt 里加一句类似：

   > 你是一个严格基于本地知识库的问答助手。只根据检索到的文档内容回答问题。
   > 如果文档中没有相关信息，你必须回答“本地知识库中没有相关信息，我无法回答”，不要自行推测或编造内容。

3. 保存更新工作区。

## 六、接入 DeepSeek API（这一步会“上云”）

如果你**仍然希望用 DeepSeek Token API 做 LLM**（而不是本地 DeepSeek 模型），那就需要把 LLM 提供商改成 DeepSeek。**注意：从这一刻起，你的提问内容会通过 HTTPS 发到 DeepSeek 云端**。deepseek.com

### 6.1 获取 DeepSeek API Key

1. 注册/登录 DeepSeek 开发者平台：[https://api.deepseek.com](https://api.deepseek.com/)deepseek.com
2. 进入 **API 管理**，创建一个新的 API Key，复制保存好（只显示一次）。tsight.io+1

### 6.2 在 AnythingLLM 中配置 DeepSeek API

1. 打开 AnythingLLM 设置 →

    

   LLM Preference

   ：

   - Provider：选择 **DeepSeek**（如果没有就选 “OpenAI compatible”，手动填 base_url）。
   - Base URL：`https://api.deepseek.com`
     （这是官方 OpenAI 兼容的 base_url）deepseek.com
   - API Key：粘贴你刚拿到的 API Key。
   - Model：填 `deepseek-v4-flash` 或 `deepseek-v4-pro`（按你购买的套餐来），官方文档推荐用这两个新模型 ID。deepseek.com

2. 保存设置。

> 配置之后，AnythinLLM 会把你的问题 + 检索到的文档片段一起发到 DeepSeek API 做生成，**这些内容会经过 DeepSeek 服务器**，注意不要把高度敏感信息原样丢进去。

### 6.3 DeepSeek API 的隐私/安全建议

1. **尽量减少敏感信息进入 DeepSeek API**

   - 对身份证号、银行卡号、内部项目代号等，在进入 API 前做掩码/删除。

   - 可以在 AnythingLLM 的 System Prompt 里加一句：

     > 对于涉及敏感信息的问题，请在回答时对身份证号、银行卡号等关键信息进行掩码处理。

2. **在 DeepSeek 账户里关闭“训练用途”**

   - 登录 DeepSeek 控制台 → 设置/隐私偏好 → 关闭类似“参与改进计划”“允许使用数据训练模型”的选项。deepseek.com
   - 这样 DeepSeek 虽然还会临时处理你的请求，但**不会默认把你的数据用于模型训练**。

3. **API Key 安全**

   - 不要把 Key 硬编码在代码或配置文件里，尽量用环境变量。baidu.com
   - 可以在 DeepSeek 控制台设置 IP 白名单、频率上限等。baidu.com

## 七、关闭遥测 / 匿名统计（尽量减少“打电话回家”）

### 7.1 AnythingLLM 遥测

AnythingLLM 官方说明：默认会收集匿名使用统计（安装类型、文档事件、向量库类型、LLM 提供商等，**不含聊天内容**）。csdn.net
如果你非常在意，可以关闭：

- 在 AnythingLLM 设置 → **Privacy & Data / 隐私和数据** → 关闭 **Anonymous Telemetry Enabled**。csdn.net
- 或者在 `storage` 目录下创建 `.env` 文件，写入：

```
  DISABLE_TELEMETRY=true
```

### 7.2 Ollama 遥测

Ollama 默认也有匿名统计，可通过环境变量关闭（官方文档和社区实测）：readthedocs.io+1

- 新建系统环境变量：
  - 变量名：`OLLAMA_DISABLE_TELEMETRY`
  - 变量值：`1`
- 重启 Ollama 服务。

## 九、如果你想“彻底零上传”的替代方案

如果你后来发现：**哪怕提问内容发到 DeepSeek 也不行**，那就不要用 DeepSeek API，改成：

- LLM 提供商：**Ollama**
- Model：`deepseek-r1:7b`（本地）
- Embedding：Ollama + `nomic-embed-text`
- 向量库：LanceDB（本地）

这样就是**完全离线可用、数据零上云**的本地 RAG 知识库。csdn.net+1
