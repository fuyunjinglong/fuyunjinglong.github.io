# Taro与UniApp对比

Taro一个通用翻译官，以React为主导，同时支持Vue,强调工程化和跨端一致性，与React Native深度绑定，更适合需要长期演进、追求极致性能和复杂工程治理的项目。

|                | UniApp                 | Taro                         |
| -------------- | ---------------------- | ---------------------------- |
| 技术栈定位     | Vue专属跨端框架        | 跨端统一框架，React主导      |
| 多端覆盖       | 小程序、H5、鸿蒙等     | 小程序、H5、鸿蒙等           |
| 开发体验       | 学习曲线平滑、社区强   | 工程化更强，TypeScript友好   |
| 性能与原生能力 | App-plus原生引擎+插件  | React Native+原生桥接        |
| 生态与国际化   | 国内服务适配强         | React/RN 全球生态广          |
| 团队门槛       | vue零门槛              | React团队更自然              |
| 治理与扩展     | 快速集成即插即用       | 模块工程与中间层治理         |
| 适用阶段       | 0-2年入口型应用        | 3-5年复杂移动产品            |
| AI集成         | 端侧集成简易，轻量场景 | 混合原生与端侧推理，长线优化 |
