WebAssembly和Rust

2001-02-01 G_其他 评论

WebAssembly

一、定义

WebAssembly（常缩写为 Wasm）是一种安全、可移植、接近原生执行效率的二进制指令格式，最初为了让 C/C++/Rust 等语言能高效地在浏览器中运行，同时也被设计成可在浏览器之外的各种环境运行的可移植“编译目标”。

二、本质

  • 二进制指令格式：采用紧凑的二进制编码，体积小、加载快，适合网络传输。
  • 面向栈的虚拟机：WebAssembly 的执行模型是面向栈的虚拟机（类似于一种抽象的汇编语言），不绑定任何特定的高级语言或硬件架构。
  • “编译目标”：大多数开发者不会直接手写 WebAssembly，而是把 C/C++/Rust/C#/Go 等语言编译成 .wasm 文件，然后在浏览器或运行时里加载执行

三、使用场景

  • 游戏、3D/物理模拟、图形处理等需要大量计算与渲染的应用。
  • 图像/视频处理、音频/信号处理、编解码、加密与安全计算等。
  • 科学计算、数据分析、CAD/CAE 等工程类软件的 Web 化。
  • 将现有的 C/C++/Rust 等生态库移植到 Web 上复用，减少重写成本

四、设计目的

  • 安全与沙盒：代码在内存安全、受控的沙盒环境中运行，防止数据损坏或安全漏洞；在网页中会遵守同源策略与权限策略。
  • 接近原生性能：利用现代硬件的共性能力，通过 JIT/AOT 等方式高效执行。
  • 可移植与平台无关：一份 .wasm 可以跨不同操作系统、CPU 架构与设备运行（从浏览器到服务器到边缘设备）。
  • 紧凑表示与快速加载：二进制格式小，可流式解码与编译，提升首屏或启动体验。
  • 语言中立与开放标准：不偏向任何一种语言或对象模型；在 W3C 社区组和工作组的公开流程下演进，主要浏览器厂商参与其中。
  • Web 平台兼容性：与 JavaScript 在同一语义宇宙中运行，可以相互调用；仍通过浏览器 Web API 去访问 DOM/网络/存储等能力，保持 Web 平台的安全模型与版本化演进方式。

五、浏览器里如何使用

  • 用支持的语言（如 C/C++/Rust/C#/Go）编写算法或核心逻辑。
  • 编译为 .wasm 二进制模块（常用工具链如 Emscripten、wasm-pack 等）。
  • 网页中的 JavaScript 通过 WebAssembly JavaScript API 加载并实例化 .wasm，然后调用其导出的函数完成计算密集任务。

六、与JS关系

  • 不是替代，而是互补：JS 继续负责 UI、交互、调用 Web API 等，Wasm 承担 CPU 密集型或已有高性能库的计算任务。
  • JS 与 Wasm 可以相互调用、共享内存，实现灵活的集成方案。

七、最佳实践

  • 从语言与工具链入手：Rust（wasm-pack）、C/C++（Emscripten）、AssemblyScript/其他 .NET、Go 等生态都有成熟路径。
  • 掌握 JS 与 Wasm 的互操作基础：如何传递数值、如何在“线性内存”中搬移数据、如何减少跨边界调用开销。
  • 关注工具与调试：浏览器的开发者工具中查看 .wasm 的文本形式、断点调试、性能分析等。

Rust

一、定义

Rust 是一门专注于安全、性能和并发的系统编程语言，由 Mozilla 员工 Graydon Hoare 于 2006 年作为私人项目启动，2009 年获得 Mozilla 赞助，2015 年 5 月正式发布 1.0 稳定版本。它通过独特的”所有权系统”（Ownership）和”借用检查器”（Borrow Checker），在不依赖垃圾回收机制（GC）的前提下，保证了内存安全和线程安全

二、核心特性

  • 高性能：Rust 速度惊人且内存利用率极高，没有运行时和垃圾回收，能够胜任对性能要求极高的服务，可以运行在嵌入式设备上，并能轻松与其他语言集成。
  • 可靠性：丰富的类型系统和所有权模型保证了内存安全和线程安全，能在编译期就消除大量常见的 Bug（如空指针、缓冲区溢出、数据竞争等）。
  • 生产力：拥有完善的文档、友好的编译器和清晰的错误提示信息，集成了包管理器 Cargo、构建工具、代码格式化工具 rustfmt 等一流工具链

三、应用场景

  • 命令行工具（CLI）：利用强大的生态快速构建可分发的命令行应用
  • WebAssembly：为 JavaScript 应用提供高性能模块
  • 网络服务：可预测的性能、极低的资源占用、坚如磐石的可靠性
  • 嵌入式系统：在资源受限的设备上获得底层控制能力，同时保留高层语言的便利性

工业界的实际应用

全球已有数百家公司在生产环境中使用 Rust，许多知名软件都在其中——例如 Firefox、Dropbox、Cloudflare。它也被应用于 Windows 内核、Linux 内核、Chromium 浏览器、AWS S3 核心存储服务等项目中；微软宣布将在 2030 年前用 Rust 重写 Windows 和 Azure 的全部 C/C++ 代码，已完成约 36000 行 Windows 内核代码的重构

四、设计哲学

Rust 是一门静态强类型的多范式语言，语法上与 C++ 相似（花括号代码块、相同的控制流关键字），但深层设计更接近函数式语言（如 Haskell），几乎函数体的每个部分都是表达式。它强调三个关键点：安全、内存布局控制、并发，旨在优雅地解决高并发和高安全性系统的问题github.io+1。

其最独特的设计是借用检查器——编译器会在编译期间追踪程序中所有引用的对象生命周期，从而在不需要垃圾回收器的情况下同时保证内存安全和防止数据竞争
